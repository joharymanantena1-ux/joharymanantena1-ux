## ⚙️ Ma méthode de travail

```mermaid
flowchart LR
    A["🎯 Cadrage<br/>du besoin"] --> B["🎨 Maquette<br/>Figma"]
    B --> C["🏗️ Architecture<br/>& modèle de données"]
    C --> D["💻 Développement<br/>par itérations"]
    D --> E["🧪 Tests<br/>& revue de code"]
    E --> F["🚀 Déploiement<br/>CI/CD"]
    F --> G["📊 Retours<br/>& améliorations"]
    G --> D
```

**En pratique :** comprendre avant de coder, maquetter avant de construire, livrer petit et souvent, puis écouter les retours des utilisateurs.
